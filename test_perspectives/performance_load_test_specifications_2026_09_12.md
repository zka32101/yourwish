## 💾 **メモリ使用量テスト**

### 計測項目

```
【起動時】
  - 初期メモリ: 150-200 MB (期待値)
  - Heap Size: < 300 MB
  - ネイティブメモリ: < 50 MB

【ゲームプレイ中（10分）】
  - メモリ増加率: < 50 MB / 5分
  - ピークメモリ: < 400 MB
  - GC 実行頻度: < 1回/分

【継続プレイ（30分）】
  - メモリリーク検出: なし
  - 最終メモリ: 初期値 + 100 MB以内
  - OOM（Out of Memory）: なし

【計測方法】
  adb shell dumpsys meminfo [package_name]
  - Native Heap: [size] KB
  - Dalvik Heap: [size] KB
  - Total: [size] KB
```

### メモリリーク検出

```
【確認手順】
1. アプリ起動状態で初期メモリ記録
2. 各機能を5分間使用 → GC発生を待つ
3. 機能終了後のメモリ記録
4. 差分 > 20 MB → 潜在的メモリリーク

【対象機能】
  - ローカル対局 (5分)
  - ネットワーク対局 (5分)
  - 広告表示 (5分)
  - ガチャ実行 (5分)
  - 棋譜再生 (5分)
```

## 🔋 **バッテリー消費テスト**

### 計測方法

```bash
【前提】
  - エミュレータ起動状態から計測
  - WiFi 接続（通信安定）
  - 画面輝度 50%固定
  - スピーカー音量 50%固定

【計測】
adb shell "dumpsys batterymanager" | grep level

【測定項目】
  1. 待機時消費: -1% / 5分
  2. プレイ時消費: -5% / 5分（目標）
  3. WiFi通信時: -3% / 5分
  4. 広告表示時: -4% / 5分
```

### バッテリー分析

```
【計測期間】
  初期バッテリー: 100%
  計測時間: 30分連続プレイ

【期待値】
  ゲーム30分 → 85-90% 残量
  = 消費 10-15%
  = 約 3.3%/分

【許容範囲】
  < 4%/分 (通常プレイ)
  < 5%/分 (WiFi + 広告)
```

## 🌐 **ネットワーク&通信テスト**

### 帯域幅測定

```
【計測項目】
  - 初期化時: 200-500 KB
  - 対局中/ターン: 50-100 KB
  - チャット送受信: 1-5 KB
  - 棋譜アップロード: 5-20 KB
  - 広告ダウンロード: 500KB-1MB

【総合消費】
  30分連続プレイ: 5-10 MB (期待値)

【計測方法】
  adb shell dumpsys netstats
  または
  Android Studio → Profiler → Network
```

### 遅延&タイムアウト

```
【ネットワーク遅延テスト】
  - 通常環境: Latency < 100ms
  - 低速環境（3G模擬）: Latency < 500ms
  - 高遅延環境: Latency = 1000ms + パケット損失 10%

【期待動作】
  - 通常: リアルタイム同期（< 200ms）
  - 低速: 遅延は許容（表示更新は遅延化）
  - 高遅延: タイムアウト処理（30秒）→ 自動敗北

【計測ツール】
  Android Studio Network Profiler
  または
  tc (Traffic Control) コマンド
```

## 📱 **CPU使用率テスト**

### CPU 計測

```
【計測項目】
  1. 起動時: < 60% CPU 使用率
  2. メニュー操作: < 30% CPU
  3. ゲームプレイ: < 70% CPU
  4. AI 思考中: 90-100% CPU（1CPU コア）

  - 平均: 40-50% (通常プレイ)

【計測方法】
  adb shell top -n 1
  または
  Android Studio → Profiler → CPU
```

```
【確認項目】
  - UI スレッド: < 16ms / フレーム
  - ワーカースレッド: AI計算専用
  - ネットワークスレッド: 非同期実行

【期待】
  - フレームレート: 60 FPS (smooth)
  - フレームドロップ: < 5% / 分
  - ANR: 0件（テスト期間中）
```
