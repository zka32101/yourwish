# ウィジェット画像の仕様

ウィジェットは静止画のみ（動画不可）。表示する画像は `imageKey` で選ぶ。

## ファイル名
`<stage>_<mood>.png`（小文字、アンダースコア区切り）。例: `adult_happy.png`

| stage | 意味 |
|---|---|
| egg | たまご |
| child | こども |
| adult | おとな |
| special | とくべつ |

| mood | 意味 | ひとこと |
|---|---|---|
| happy | 今日できた | きょうもできたね！ |
| resting | おやすみカード使用 | きょうはゆっくりおやすみ |
| waiting | 夕方前・未達成 | きょうのひとつ、いっしょにやろう |
| restless | 18時以降・未達成 | まだだいじょうぶ、ひとつだけやってみる？ |
| lonely | 3日以上空いた | また会えるのを、まってるよ |

ステージ4 × 表情5 = **20枚**が基本セット（`egg_happy.png` 〜 `special_lonely.png`）。

## 仕様
- 形式: PNG（透過）または WebP。1枚あたり 200KB 以下を目安（Android の RemoteViews 転送制限対策）
- サイズ: 正方形 512×512px。小ウィジェットは顔のアップが読める構図にする
- 余白: 外周に 8% 程度の透過余白（角丸ウィジェットで切れないように）
- 世界観: ほしぞら森、パステル、まるいフォルム。表情が一目で分かること
- 「さみしそう」「そわそわ」でも泣き顔・怒り顔にしない（責めない表現）

## 置き場所
- アプリ内: `assets/widget/<imageKey>.png`（pubspec の `flutter: assets:` に追加）
- Android: `res/drawable-nodpi/` に同名（小文字・数字・_ のみ）で配置
- 画像が見つからない場合は `<stage>_waiting` → 絵文字、の順にフォールバックする（ネイティブ側で実装）

## 将来の拡張
- 時間帯の背景（朝/昼/夕/夜）、季節・イベント限定画像は `imageKey` に接尾辞を追加して対応（例: `adult_happy_night`）
